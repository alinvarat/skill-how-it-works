# how-it-works

Explain how a subsystem, feature flow or codebase works at senior-onboarding depth, and optionally critique its architecture with independent Claude critics. Use on "how does X work", "walk me through", "อธิบายระบบนี้", "critique this architecture".

Part of [agent-skills](https://github.com/alinvarat/agent-skills). Install: copy or symlink this folder into `~/.claude/skills/how-it-works`.

Based on [poteto/how](https://github.com/poteto/how) by Lauren Tan (MIT). See `references/NOTICE.md`.
